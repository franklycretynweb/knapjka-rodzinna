# Knajpka Rodzinna × PARTY TENT

Wierna statyczna kopia publicznej strony przygotowana do wdrożenia na Vercel.

## Wdrożenie

1. W Vercel wybierz **Add New → Project → Import Third-Party Git Repository** albo przeciągnij ten katalog do panelu.
2. Framework preset ustaw na **Other**.
3. Build command pozostaw puste, a output directory ustaw na `.`.
4. Kliknij **Deploy**.

Strona korzysta wyłącznie z oryginalnych plików HTML, CSS, JavaScript i obrazów — nie wymaga instalowania zależności ani zmiennych środowiskowych. Formularz kontaktowy przygotowuje wiadomość w domyślnym programie pocztowym.

Ważne: w Vercel wybierz katalog zawierający bezpośrednio `index.html`, `site.js`, `styles.css` i folder `assets`.
